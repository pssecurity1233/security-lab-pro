# Quick Start Guide

## Installation (3 commands)

```bash
git clone https://github.com/yourusername/security-lab-pro.git
cd security-lab-pro
sudo bash scripts/install/install.sh --full
```

## First Steps

1. Verify services: `bash scripts/operations/health-check.sh`
2. Access dashboard: http://YOUR-IP:8888
3. Run test: `bash tests/integration/simulate-attack.sh`
